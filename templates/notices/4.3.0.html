Weather Control

This fork is maintained for Warhammer Fantasy Roleplay 4th Edition (WFRP4e). Use Simple Calendar Reborn (required dependency) for the current date and season. Daily weather defaults to the Deft Steps, Light Fingers procedure (four separate 1d10 rolls for Temperature, Precipitation, Visibility, and Wind, with seasonal and optional environmental modifiers). You can enable legacy Enemy in Shadows (seasonal 1d100 + DWD-style temperature walk) in module settings if you prefer the older table.

What this module does

  • Calendar integration — season from Simple Calendar or a fixed season (Auto / Spring / Summer / Autumn / Winter).
  • DSLF weather (default) — four columns, WFRP-oriented labels, short mechanical reminders in chat and panel.
  • Legacy weather (optional) — Enemy in Shadows–style seasonal 1d100 categories and German reference temperature profiles.
  • Chat & panel — optional output to chat; floating weather panel with temperature and conditions.
  • Scene weather — drives Foundry’s weather layer; FXMaster remains optional.
  • Settings — Celsius/Fahrenheit, player visibility, DSLF environmental modifiers, and more.

Project: github.com/ricardopiloto/weather-control (source, issues, and releases).

Configure Simple Calendar in your world, enable Weather Control, and see the README on GitHub for full setup.
